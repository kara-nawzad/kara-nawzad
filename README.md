## Hi, I'm Kara 👋

I'm a Communication Engineer from Sulaymaniyah, Kurdistan. I build AI-powered tools for network monitoring, fiber design and antenna design, and I put them live so people can actually try them.

## 🚀 What I'm building

- **AntDesigner:** AI antenna design tool. Designs an antenna in 3 seconds with 94.76% accuracy (my graduation project)
- **SuliNOC:** AI-powered network operations dashboard that spots early warning signs in a mobile network
- **FiberLAB:** interactive fiber network design and fault-finding trainer
- **KurdLine:** Kurdistan network planning platform combining fiber, microwave, satellite and 5G (in development)

## 🎓 Background

- Intern at Asiacell (SOC) and Halabja Group Telecom Services
